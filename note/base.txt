사전 준비
1. Node.js를 설치한다. (이때 npm도 같이 사용 가능해 짐)
2. 리액트 프로젝트를 생성한다.
3. cmd에 "npm run dev"를 이용해 페이지를 확인한다. (q를 눌러 종료)

깃 관련
. "npm run deploy"를 이용해 배포한다.


리액트 라우터 (react-router)
=> 물리적인 html페이지를 만들지 않고도 하나의 html(ex: "index.html")파일 만으로 
'(주소)/study', '(주소)/home'등의 url 구성을 가능케 하는 것
=> SPA(Single Page Application) 라우팅

해시 라우터 (HashRouter)
=> 새로고침 등의 이슈 : 물리적인 html페이지가 존재하는 것이 아니라서, 새로고침 등의 경우
페이지를 찾지 못하게 됨
=> 해시라우팅으로 '(주소)/#/(route)'방식의 url 구성이 가능
=> 서버는 해시(#) 뒤쪽의 키워드를 무시함으로써 이슈를 해결 가능

주소와 화면의 연동:  아래-좌측 영역의 <Link to="/home">을 누르면 브라우저 주소창이 (도메인)/#/home으로 변경됩니다. 동시에 아래-우측 영역의 <Routes>가 이를 감지하여 path="/home"에 지정된 "반갑습니다." 컴포넌트를 그 자리에 띄워줍니다.

기본값 설정: 처음 블로그에 접속했을 때는 아무것도 안 누른 상태이므로, <Navigate to="/home" /> 코드가 작동하여 자동으로 home 메뉴가 선택된 상태로 시작하게 됩니다.
